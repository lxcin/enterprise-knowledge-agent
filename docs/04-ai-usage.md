# AI 使用说明

Codex 协助架构讨论、Python 代码、模型接口、合成材料、测试和交付文档。真实问答与语义审核使用用户授权的 DeepSeek 服务。离线编排测试使用预设动作，接口测试使用模拟响应。

用户提供需求与验收标准，确认关键词和多跳检索方向，要求处理 PDF 图表、以原件审核并移除 Markdown 调试导出。后续用户推动一次检索返回充分证据、双语查询、可选向量接口，以及制度问题先检索的系统提示词。这些属于已记录的人工决策。当前没有可核实的人工直接代码编辑。

验证同时保留成功、失败和复跑记录。开发机向量实验被明确标记为历史原型，当前使用显式提供的模型配置。密钥通过环境传入，示例文件仅保留变量名。不能仅以模型自评或测试状态代替对原文的人工核对。
